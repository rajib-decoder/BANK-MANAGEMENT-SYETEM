🏦 Banking Management System
A simple Python + MySQL Banking Management System that allows users to manage bank accounts and perform basic banking operations through an interactive menu-driven interface.
```
✨ Features
🆕 Create New Bank Accounts
👤 Display Customer & Account Details
💰 Deposit Money
💸 Withdraw Money
📊 Check Account Balance
🔄 Transfer Money Between Accounts
📋 Display All Bank Accounts
❌ Close Bank Accounts
🛠️ Technologies Used
Python – Programming Language
MySQL – Database Management
MySQL Connector – Python-MySQL Connectivity
⚙️ Setup & Installation
Install the required library:
```
```
bash
pip install mysql-connector-python
Create a MySQL database named Bank.
Configure your MySQL credentials in the Python file.
Run the program:

bash
python main.py
```
🎯 Project Purpose
This project is designed to practice Python programming, MySQL database connectivity, SQL queries, CRUD operations, and basic banking transactions.
